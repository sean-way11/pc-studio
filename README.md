# PC Studio

Приложение для Windows 10 и Windows 11: диагностика загрузки и дисков, доступ к настройкам и запуск встроенных средств проверки и восстановления Windows.

## Запуск
Скачайте `PC-Studio.exe` из релиза и запустите. Установка не требуется. Приложение использует установленный в Windows .NET Framework 4.x. Файл не подписан цифровой подписью; Windows может показать предупреждение SmartScreen.

## Возможности и ограничения
- Отображение данных процессора, оперативной памяти и локальных дисков.
- Запуск SFC /verifyonly, SFC /scannow, DISM /ScanHealth и DISM /RestoreHealth с подтверждением и запросом прав администратора. Средства работают в отдельном системном окне, результат необходимо прочитать там. DISM RestoreHealth может использовать интернет.
- Ссылки на системные настройки автозагрузки, памяти, питания, интерфейса и обновлений. Их наличие зависит от версии Windows.
- Приложение не гарантирует обнаружение или исправление всех проблем и не ремонтирует оборудование. Восстановление может изменить системные файлы; операции не запускаются автоматически.

## Сборка
На 64-битной Windows с .NET Framework 4.x выполните `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1`. Исходники: Program.cs и MainWindow.xaml.

## Проверка
Проверены запуск и диагностика на одном ПК с Windows 11, визуальный интерфейс, предупреждение перед SFC и переход в настройки автозагрузки. Проверка собственно восстановления, всех системных ссылок и Windows 10 ещё необходима.
