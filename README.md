# PC Studio — beta

Windows-приложение для диагностики и выбранных пользователем настроек быстродействия. Установка не требуется; нужен .NET Framework 4.x в Windows 10 или 11. EXE не подписан, поэтому Windows может показать SmartScreen.

## Оптимизация
Во вкладке «Оптимизация» можно выбрать отключение клиентской анимации Windows и план питания высокой производительности. После нажатия «Применить выбранное» программа применяет настройки и сохраняет прежние значения в `%LOCALAPPDATA%\PCStudio\optimization-backup.txt`; кнопка возврата восстанавливает их. На некоторых компьютерах высокопроизводительный план недоступен. На ноутбуке он может повысить расход батареи и нагрев. Эти действия не гарантируют повышение скорости или FPS.

## Системные ошибки
Во вкладке восстановления доступны встроенные SFC и DISM. Проверка и восстановление запускаются по выбору пользователя с запросом администратора; результат отображается в отдельном окне. Восстановление может изменить системные файлы; DISM может использовать интернет. Приложение не исправляет все ошибки ПК.

## Состояние проверки
На Windows 11 проверено открытие окна и экран выбора. Применение, повторное применение и возврат проверены в имитации без изменения Windows; фактическое применение и откат на Windows 10 и 11 ещё не проверены. Устранять системные ошибки автоматически без выбора и подтверждения программа не будет.

## Сборка
Запустите `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1` на Windows с .NET Framework 4.x. Исходники: Program.cs и MainWindow.xaml.
